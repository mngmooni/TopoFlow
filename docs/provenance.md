# Data and code provenance

The authoritative public source was assembled from the final verification package. Earlier original ZIP snapshots supplied to the project owner represent cumulative stages of the investigation; overlapping source files were checksum-compared and found identical. Earlier structured JSON/JSONL/PNG result artifacts were selectively restored **without editing their bytes**. Some public report copies have only calendar-label wording normalized; originals remain in the immutable private archives. A complete source-file-level mapping and SHA-256 hashes are preserved in the private migration inventory.

Existing reconstructed Git history was assembled from source ZIPs after the research work. This public package does not include that `.git` directory and should not imply that reconstructed commits occurred contemporaneously with experiments.

The public source uses descriptive filenames. Historical experiment paths are recorded in private provenance; the original source archives remain immutable.
